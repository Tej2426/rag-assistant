Why this isn't just a docs chatbot

Reads the actual source

Source is chunked on function/class boundaries with an AST parser, not naive text splitting — every code citation is a complete, syntactically valid unit, never half a function.

Says "I don't know" on purpose

The model is instructed to answer only from retrieved context and admit when it doesn't know — the failure mode that matters most for a tool people are meant to trust.

Measured, not assumed

Ships with an evaluation harness scoring retrieval and answer quality against a fixed question set, so retrieval changes can be checked against a number, not a vibe.
